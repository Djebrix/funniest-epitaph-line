One funny line of famous last words, carved as a tombstone epitaph — 59 characters, at most 150 allowed.

> My last words were "watch this." You're reading the result.

`main.py` (Python 3, stdlib only) writes the line to `/output/entry.txt`, deterministically — the same bytes on every run.
